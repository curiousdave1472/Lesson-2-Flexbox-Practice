## Flexbox Practice
Your job is to redesign the BuzzFeed Navigation Bar three different ways using Flexbox and Box Model however you'd like!

Using CSS style each sample nav bar differently using flexbox and the properties like justify-content, border, padding, margin, font-color, background-color, etc.

Remember to apply flexbox each time to the parent element using the display property.

Experiment with different properties and aim to make each of your samples very different from the prior ones!
